# 🐙 GitHub Quick-Start (no command line needed)

Everything below works in your **web browser**.

---

## 1 · Create your account *(before Day 1)*

1. Go to [github.com/signup](https://github.com/signup)
2. Use an email you check regularly, and choose a **professional username** (e.g., `ahmed-alharbi`). Employers may see it!
3. **Verify your email.** Your account isn't active until you do.
4. Recommended: turn on **two-factor authentication** (Settings → Password and authentication)

---

## 2 · Create your project repository

1. Click **➕** (top right) → **New repository**
2. **Repository name:** `meeting-followup-assistant`
3. **Description:** `Final project for L0-FGP Generative AI for Productivity (SDAIA Academy)`
4. Choose **Public**
5. Click **Create repository**

---

## 3 · Upload the template

1. Download and unzip the `template` folder
2. In your new repository, click **Add file → Upload files**
3. Drag **the contents** of the template folder (not the folder itself) into the page
4. Write a clear commit message: `Add project template`
5. Click **Commit changes**

---

## 4 · Work step by step: one commit per step ✅

For each project step, open the file on GitHub → click the **✏️ pencil (Edit)** → paste your work → **Commit changes** with a clear message.

| Step | Example commit message |
|---|---|
| 1 | `Add extraction prompt (before and after)` |
| 2 | `Add follow-up email` |
| 3 | `Add data summary for task tracker` |
| 4 | `Add source verification and corrections` |
| 5 | `Add Meeting Follow-up Assistant instructions and test` |
| 6 | `Add safety review` |
| 7 | `Complete README and documentation` |

**Good commit messages:** start with a verb, say *what* changed, and stay short.
❌ `update` · `asdf` · `final final 2`  ✅ `Fix invented owner in action items`

> 💡 To upload a screenshot: open the folder (e.g., `assistant/`) → **Add file → Upload files**.

---

## 5 · Publish version 1.0 🏷️

1. On your repository page, click **Releases** (right side) → **Create a new release**
2. **Tag:** `v1.0` · **Title:** `Version 1.0 - Course submission`
3. Write 2–3 lines about what's included → **Publish release**

---

## 6 · Submit

Copy your repository link (e.g., `https://github.com/your-username/meeting-followup-assistant`) and submit it as your trainer instructs.

---

## 🌍 Community actions (1 minute each)

| Action | How |
|---|---|
| ⭐ Star a repository | Open it → click **Star** (top right) |
| 👤 Follow an account | Open the profile → click **Follow**. Start with [SDAIA Academy](https://github.com/SDAIAAcademy) |
| 🔁 Fork | Open a repository → **Fork** → creates your own copy to experiment with |
| 🐞 Open an issue | Repository → **Issues** → **New issue** to report a problem or suggest an idea |
| 🔀 Pull request | After changing your fork → **Contribute → Open pull request** to propose your change |
